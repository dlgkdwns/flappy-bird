# 플랜비버드

Canvas로 만든 단일 파일 플래피 버드 게임.

## 플레이

`flappy.html`을 브라우저로 열면 바로 실행됩니다.

- **조작**: 클릭 / 스페이스바 / 터치로 날갯짓
- 파이프 사이를 통과하면 점수 획득
- 최고 점수는 브라우저(localStorage)에 저장

## 난이도

파이프 간격은 파이프마다 무작위로 정해지며, 점수가 오를수록 범위가 좁아집니다.

| 점수 | 간격 범위 |
|------|-----------|
| 0    | 130–175px |
| 10   | 116–159px |
| 25+  | 95–135px  |

물리 상수(`GRAVITY`, `FLAP`, `SPEED`, `PIPE_GAP_MIN/MAX`)는 `flappy.html` 상단에서 조정할 수 있습니다.
