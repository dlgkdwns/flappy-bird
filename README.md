# 플랜비버드

Canvas로 만든 단일 파일 플래피 버드 게임.

## 플레이

`flappy.html`을 브라우저로 열면 바로 실행됩니다.

- **조작**: 클릭 / 스페이스바 / 터치로 날갯짓
- 파이프 사이를 통과하면 점수 획득
- 최고 점수는 브라우저(localStorage)에 저장

## 난이도

파이프 간격(95~175px)은 매번 이 범위 전체에서 무작위로 뽑혀 절대 일정해지지 않습니다.
점수가 오를수록 좁은 쪽으로 확률이 쏠리지만, 약 18% 확률로 극단적으로 좁거나 넓은
파이프가 섞여 언제든 예측 불가능한 리듬이 나옵니다.

| 점수 | 대략적인 중앙값 |
|------|-----------------|
| 0    | ~133px (여유로움) |
| 10   | ~116px |
| 20+  | ~110px (빡빡함) |

물리 상수(`GRAVITY`, `FLAP`, `SPEED`, `PIPE_GAP_MIN/MAX`)는 `flappy.html` 상단에서 조정할 수 있습니다.
